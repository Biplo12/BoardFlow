# Illustration credits

`peeps/figure/*.svg` and `peeps/avatar/*.svg` are compositions of **Open Peeps**
by Pablo Stanley, released under **CC0 1.0 Universal** (public domain).

- Collection: https://www.openpeeps.com/
- SVG atoms taken from https://github.com/jenshor/open-peeps
  (`packages/open_peeps/assets/atoms`, MIT-licensed wrapper around the CC0 art)

Each file stacks a pose, a head, a face and an optional accessory onto one
canvas, then recolours the artwork's background layer with a palette tint from
`app/globals.css`. CC0 requires no attribution; this note records provenance.
